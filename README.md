# Проект: Реализация моделей освещения и текстурирования

Этот проект реализует различные модели освещения и алгоритмы текстурирования для 3D-моделей с удалением нелицевых граней.

## Функциональность

### 1. Модели освещения

#### 1.1 Шейдинг Гуро (модель Ламберта)
- Вычисление нормалей к каждой вершине (из OBJ-файла или расчет)
- Определение положения источника света и цвета объекта
- Расчет цвета в каждой вершине по модели Ламберта (диффузное отражение)
- Билинейная интерполяция цвета между вершинами для закраски граней
- Поддержка аффинных преобразований объектов

#### 1.2 Шейдинг Фонга (туншейдинг)
- Билинейная интерполяция нормалей между вершинами
- Нормализация интерполированных нормалей
- Расчет цвета в соответствии с моделью Фонга
- Реализация туншейдинга с интерполированными нормалями

### 2. Текстурирование
- Алгоритм наложения текстуры на полигоны
- Добавление текстурных координат к вершинам
- Интерполяция текстурных координат между вершинами
- Демонстрация на правильных многогранниках:
  - Тетраэдр
  - Куб
  - Октаэдр
- Поддержка преобразований текстурированных объектов

## Технические особенности

- Удаление нелицевых граней для оптимизации рендеринга
- Загрузка 3D-моделей из OBJ-файлов
- Поддержка аффинных преобразований (перемещение, вращение, масштабирование)
- Эффективные алгоритмы интерполяции

## Демонстрация

Проект включает демонстрационные сцены, показывающие:
- Различные модели освещения на 3D-моделях
- Текстурирование правильных многогранников
- Эффекты аффинных преобразований
